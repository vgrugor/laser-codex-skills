# Scorecards

Use these scorecards when a concept, sketch, DXF, or prototype needs formal review. Score 1-5 unless noted.

## Concept Scorecard

| Criterion | Score | Notes |
| --- | ---: | --- |
| Buyer clarity |  | Is the product clearly for someone specific? |
| Premium look |  | Does it look above average before explaining it? |
| Originality |  | Does it avoid generic template energy? |
| Composition |  | Is there a clear focal point and enough negative space? |
| Layer logic |  | Do layers improve the design instead of adding clutter? |
| Color logic |  | Are stains restrained and coherent? |
| Hardware fit |  | Does hardware support the intended price tier? |
| Manufacturability |  | Can it be cut, stained, assembled, and repeated reliably? |
| Series potential |  | Can this become a collection? |
| Price justification |  | Is there a visible reason to pay more? |

Recommended thresholds:

- 42-50: strong candidate
- 34-41: promising, revise before CAD
- 25-33: weak; keep only the best idea
- under 25: reject

## Premium Design Checklist

- One dominant visual idea.
- Restraint: remove details that do not earn their place.
- Consistent radii, spacing, border widths, and line weights.
- 2-3 stains maximum for most products.
- Visible contrast between base, raised details, and engraved/cut lines.
- Hardware finish chosen intentionally: black, brass, bronze, or brushed metal.
- Mounting holes are hidden or designed as a deliberate feature.
- Personalization area does not disturb the main composition.
- The product still looks good without a long explanation.
- The design can be photographed beautifully from the first angle.

## Manufacturing Checklist

- Minimum bridges are strong enough for sanding and staining.
- Small islands are not easy to break or lose.
- Inside corners and holes suit the laser kerf and available hardware.
- Each stain group can be separated before finishing.
- Glue areas are large enough and not visible after assembly.
- Engraving/cutting order is clear in LightBurn.
- DXF files are grouped by layer, color, and operation.
- A test coupon exists for stain/lacquer combinations when finish risk is high.

## Prototype QA Checklist

- Edges are clean and do not show uncontrolled soot.
- Surface sanding is even before stain.
- Stain is consistent; no blotchy or muddy areas.
- Lacquer sheen matches the intended tier: matte/satin usually reads more premium than heavy gloss.
- Hardware is aligned and visually substantial enough.
- Text is readable and not too decorative.
- The product feels like one designed object, not assembled clipart.
- Photos show scale, material texture, and wall/use context.

## Listing Readiness Checklist

- Name sounds specific, not generic.
- Main photo communicates quality within 2 seconds.
- Description explains material, hand finishing, personalization, and use case.
- Variants are clear and not overwhelming.
- Price is supported by visible value: design, finish, personalization, hardware, packaging.
- Packaging is gift-ready if the product targets gifting.
